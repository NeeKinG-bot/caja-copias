# Caja de Copias

App para el iPhone que muestra los precios del día en bolívares según la tasa BCV y lleva las ventas, los gastos y la ganancia de un negocio de copias e impresiones.

- Se abre en Safari y se agrega a la pantalla de inicio (Compartir → Añadir a pantalla de inicio).
- Los datos se guardan en el teléfono. Usa **Ajustes → Guardar respaldo** de vez en cuando.
- Funciona sin internet después de abrirla la primera vez.
